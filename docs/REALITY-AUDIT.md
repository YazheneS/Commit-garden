# Repository Reality Audit

**Audit date:** 2026-09-27  
**Scope:** Repository reality audit plus strict runtime follow-up for TASK-044–048. This audit distinguishes source code and automated tests from runtime evidence. The garden engine and its tests have been preserved.

## Summary

This repository contains real domain logic, renderer state and an HTML/CSS scene renderer, a runnable HTTP API, live-verified PostgreSQL persistence, OAuth/session handling, contribution synchronization, and substantial desktop/mobile client source. The web package is a Vite browser application and its page plus transformed entry/style modules return successfully over HTTP. A browser DOM/visual inspection and browser-session garden rendering were not verified. Sprite metadata exists, but there are no delivered sprite-sheet image assets; the scene renderer generates CSS silhouettes/patterns rather than drawing those metadata frames.

TASK-048 live PostgreSQL verification is now complete: migrations, schema, persisted records, API restart, and PostgreSQL container restart were exercised against the local PostgreSQL instance. Remaining gaps include live API-backed browser rendering with a real GitHub garden, native desktop/mobile builds and device verification, real GitHub OAuth, and production deployment. Automated test success is not evidence for those external runtimes.

## Web runtime follow-up (TASK-045 discrepancy)

The earlier web package was only helper code and tests. It now has `apps/web/index.html`, a Vite command, browser entry and API request path. The existing server on port 5173 returned the page, entry and styles with HTTP 200. The client supplies API plant state to the shared state builder and renderer, and its primary path does not use a mock garden. API and PostgreSQL were available during this audit, but browser automation was not; the browser DOM, visible pixel scene and authenticated garden in the browser remain unverified. The newly attempted `pnpm dev` could not bind because the already-running app held strict port 5173.

An Edge headless inspection attempt did not produce a screenshot; browser DOM/visual state therefore remains unverified.

The repository has been identified and should continue to be described as a **validated scaffold with substantial implemented source**, not a deployed product or production-ready MVP. Automated checks do not prove live database durability, external authentication, native app behavior, or production operations.
